## 현재 체크포인트 — 2.5 전체 검토

### 2단계에서 구현한 것

- 공개 Archive와 분리된 `/archive-v1/admin/` 관리자 작업대
- 왼쪽 메뉴: 전체 흐름 / 새 자료 등록 / 분류 검토 / 관계 검토 / 발행 대기 / 회의 작성 연결
- 새 자료 최소 입력 → AI 분석 결과를 가정한 초안 생성 → 분류 검토 이동
- 분류 검토: 주제 / 조직 / 현행상태 / 신뢰도, 승인 / 수정 / 보류
- 관계 검토: 연결 대상 / 관계 종류 / `explicit / verified / inferred`, 승인 / 연결 없이 진행
- 발행 대기: 공개등급 최종 확인 / 미리보기 / 프로토타입 발행
- `public / resident / private` 의미를 화면과 설계문서에 구분
- 회의 작성은 기존 `회의 설정 / 동대표 명단 / 안건·발언`으로 연결하고 중복 입력하지 않는 원칙 유지
- 샘플 상태는 브라우저 메모리에서만 움직이며 새로고침 시 초기화

### 의도적으로 아직 연결하지 않은 것

- 실제 관리자 인증
- GitHub/Google Drive 쓰기 API
- resident 인증
- 실제 AI 호출
- 실제 공개 검색 인덱스 갱신
- 실제 원본 업로드

이 항목들은 3~4단계의 회의 연결·저장소·권한 구조와 함께 설계한다.

- 검토 → 발행 대기까지 흐름이 번거롭지 않은지
