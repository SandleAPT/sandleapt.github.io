# 안건 제안서 작성 도구

## 목적

동별대표자가 회의 안건을 짧고 쉽게 정리해 A4 한 장으로 제출할 수 있게 하는 작은 작성 도구다.

주소:
- 포털: `/#proposalView`
- 직접 열기: `/agenda-proposal/`

## 화면

- 왼쪽: 입력 폼
- 오른쪽: A4 1장 미리보기
- 입력 항목: 안건 제목, 제안자, 제출일, 제안 배경, 주요 내용, 의결 내용, 비용, 참고할 자료
- 어려운 행정용어보다 주민이 바로 이해할 수 있는 말로 작성하도록 안내한다.
- `- `로 시작한 줄은 미리보기에서 목록으로 표시한다.

## A4 한 장 원칙

- 내용이 길어지면 문서 글자 크기와 줄 간격을 정해진 범위 안에서 자동으로 조금 줄인다.
- 그래도 한 장을 넘으면 `A4 한 장을 넘습니다. 내용을 조금 줄여 주세요.`라고 표시하고 인쇄 버튼을 잠근다.
- 인쇄 CSS는 A4 세로 1장으로 고정한다.

## 저장과 개인정보

- 서버나 GitHub에는 작성 내용을 저장하지 않는다.
- 초안은 작성한 브라우저의 `localStorage`(`sandle_agenda_proposal_v1`)에만 자동 저장한다.
- `내용 지우기`로 로컬 초안을 지울 수 있다.

## 예시

`누수 예시` 버튼은 2026-09-03 논의한 커뮤니티센터 누수·곰팡이 보수 안건을 쉬운 말로 채워 준다. 예시는 그대로 확정하는 기능이 아니라 작성 시작을 돕는 샘플이다.
