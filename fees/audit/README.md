# 경기도 공동주택관리 감사 사례집 자료 (fees/audit/)

경기도가 해마다 펴내는 「경기도 공동주택관리 감사 사례집」(2018~2025, 8권)의 지적 사례를 연도별 JSON으로 옮긴 것이다. 관리비 앱의 **감사 사례** 탭이 읽는다.

## 파일

- `index.json`: 연도 목록(파일·건수·원문 쪽 수·PDF 파일명), 표준 분류 10개, 관리비 항목 태그 11개, 집계
- `cases-YYYY.json`: 그 해 사례 목록. 각 사례는 `no`(사례집 번호), `title`, `section`(원문 장 제목), `group`(표준 분류), `tags`(관리비 항목 태그), `agency`(감사 기관), `pdfPage`/`pages`(PDF 쪽), `laws`(인용 법규 「…」 제n조), `finding`(지적 내용), `rules`(관련 규정), `text`(OCR 본문 전체), `ocrTitle`(목차로 보정하기 전 OCR 제목)

원문 PDF는 저장소에 두지 않는다. 파일명과 SHA-256은 각 연도 파일의 `source`에 있다.

## 만든 방법 (2026-09-04)

1. 원문은 한글이 텍스트로 추출되지 않는다(2022·2023은 스캔, 나머지는 글꼴 문제). `pdftoppm -r 150 -png`로 1,495쪽을 그림으로 만들고 Windows 내장 OCR(`Windows.Media.Ocr`, ko)로 읽었다. 스크립트: 세션 스크래치 `winocr-dir.ps1`(BOM 필수), `audit-run.sh`.
2. 규칙 기반으로 사례를 나눴다(`audit-parse.pl`): 감사 기관 줄(…시 …과)을 찾고 그 앞 줄을 제목으로 삼는다. 제목은 목차와 대조해 보정한다(번호 일치 + 유사도). 인용 법규는 「…」 제n조 패턴, 지적 내용은 「○○아파트 …하였음」 꼴의 문장, 관련 규정은 '관련 규정' 표제 뒤 조문.
3. `audit-build.pl`이 표준 분류·태그를 붙여 이 폴더에 쓴다.

## 한계

- OCR이라 오타가 있다(특히 2021년: 글꼴 탓에 '부적정'이 '부적점'으로 읽히는 등). 정확한 문구는 원문 쪽으로 확인한다.
- 목차 기준 789건 중 765건을 분리했다. 놓친 24건은 OCR이 제목·번호를 못 읽은 쪽이며, `index.json.years[].tocMax`와 `caseCount`의 차이로 알 수 있다.
- 지적 내용을 분리하지 못한 사례가 23건 있다(`finding`이 비어 있음). 화면은 그 경우 원문 전체를 보라고 안내한다.
- 질의회신·판례·수범사례 장은 옮기지 않았다.

## 감사 대조 (`checks.json`) — 비밀번호 탭

사례집에서 자주 지적되는 유형 31개를 골라 우리 단지 공개 자료와 견준 기록이다. 관리비 앱의 **감사 대조 🔒** 탭이 읽으며, 특정 대상자에 대한 판단이 들어가므로 열람 비밀번호 뒤에 둔다. 항목마다 `status`(위반 확인 / 해당 가능 / 확인 필요 / 이행 확인), `caseRefs`(사례집 연도·번호), `rule`, `facts`, `judgement`, `next`를 적는다. 상태를 바꿀 때는 근거가 된 자료를 `facts`에 날짜와 함께 남긴다.

## K-apt 공개 자료 (`kapt.json`, 2026-09-06)

'확인 필요' 항목을 대조하려고 공동주택관리정보시스템(K-apt)의 우리 단지 공개 화면을 옮긴 것이다. 단지코드 `A10027842`(경기도 성남시 중원구 여수동 602). 담긴 것: 관리비 공개 현황(2024~2026), 회계감사 결과(2015~2025 회계연도), 입주자대표회의 구성인원 등록값, 입찰공고 116건과 2025~2026 낙찰 결과 6건, 수의계약 결과 135건, 유지관리이력 25건, 월별 관리비·장기수선충당금·잡수입(주거전용면적 환산 근사값).

- 여는 법: k-apt.go.kr 첫 화면에서 단지명 검색 '산들마을' → '산들마을아파트 [경기도 성남중원구 여수동 602]' → 단지 검색. 이후 단지정보·관리비·회계감사·입찰정보·유지관리이력 메뉴가 이 단지 기준으로 열린다.
- 응찰업체 대표자·전화번호 같은 개인정보는 옮기지 않는다. 회사명·금액·날짜만 옮긴다.
- 네이버 카페는 이 작업 환경의 브라우저에서 열리지 않아, 카페 게시물은 회의록 앱(선거·계약 탭)에 이미 옮겨진 범위에서만 대조했다.
