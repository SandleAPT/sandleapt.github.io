Sandle Archive v1 — 브라우저 검증 러너

Node.js가 없는 환경에서 archive-v1/tests/specs/*.spec.js를 그대로 실행합니다. 케이스는 node archive-v1/tests/*.test.js와 동일하며, spec 파일 하나만 고치면 두 경로에 함께 반영됩니다.

이 러너는 정적 파일만 읽습니다. 클라우드 저장소나 관리자 비밀번호를 쓰지 않으며 어떤 데이터도 수정하지 않습니다.
Stage 3 spec은 fixture로 실행합니다(실제 /minutes/ 데이터를 읽는 live-data 검증은 별도 소번호로 추가 예정).
전역을 건드리는 spec(isolate)은 빈 iframe에서 따로 실행해 서로 오염되지 않게 합니다.
